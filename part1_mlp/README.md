# Часть 1. Объектно-ориентированный многослойный перцептрон

Сеть написана с нуля на NumPy: без TensorFlow, PyTorch и sklearn.
Один скрытый слой, сигмоида/ReLU/tanh, обучение мини-батчами,
сохранение весов в JSON.

## Запуск

```bash
cd part1_mlp
python -m app.main      # или: python app/main.py
```

## Пункты меню

1. **Создать сеть** - ввести размеры слоёв (`6, 12, 1`), выбрать
   активацию скрытых слоёв и функцию потерь:
   `bce` для классификации, `mse` для регрессии.
2. **Загрузить данные** - CSV, первая строка - заголовки, последний
   столбец - целевая переменная. Дальше выбор доли теста и способа
   нормализации (`standardize` или `minmax`).
3. **Обучить сеть** - скорость обучения, число эпох, размер батча.
   Печатается ошибка каждые 10% эпох, время обучения и точность.
4. **Предсказание** - ввод признаков вручную или CSV-файл.
5. **Сохранить веса** - JSON с архитектурой, весами и историей.
6. **Загрузить веса** - в текущую сеть или с созданием сети по файлу.
7. **График ошибки** - PNG в `docs/mlp_loss_curve.png`.

## Формулы

Прямой проход слоя:

```
Z = A_prev · W + b
A = act(Z)
```

Ошибка (бинарная кросс-энтропия) и её производная по выходу:

```
L = -mean(y·ln(a) + (1-y)·ln(1-a))
dL/da = (a - y) / (a·(1-a)) / N
```

Обратный проход: `delta = dL/da · act'(Z)`, затем
`dW = A_prevᵀ · delta`, `db = sum(delta)`, `delta_prev = delta · Wᵀ`.
Шаг градиентного спуска: `W -= lr · dW`.

Инициализация весов: Xavier для сигмоиды и tanh, He для ReLU.
